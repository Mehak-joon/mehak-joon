# Responsive Personal Portfolio Website - Mehak Joon

A modern, responsive personal portfolio website designed and developed for **Mehak Joon** (Web Developer & Computer Science Student at The NorthCap University). Built using semantic HTML5, modern CSS with responsive design principles and theme toggling, and JavaScript for interactive features and form validation.

---

## 🚀 Live Demo & Preview
To view the portfolio locally:
- Open [`index.html`](./index.html) directly in any modern browser (Chrome, Firefox, Edge, Safari), or
- Right-click [`index.html`](./index.html) in VS Code and select **"Open with Live Server"**.

---

## 🌟 Key Features

- **Responsive Navigation**:
  - Sticky glassmorphic navbar with smooth scrolling links to all sections.
  - Active section highlight (scroll-spy) based on viewport position.
  - Mobile hamburger drawer menu for screens under 768px.

- **Dark / Light Theme Toggle**:
  - Interactive theme switcher with moon/sun icons.
  - Saves theme preference to `localStorage` and respects system preferences.

- **Home / Hero Section**:
  - Personal introduction and headline.
  - Custom SVG avatar illustration of a female developer with floating tech badges and glow effects.
  - Quick action buttons (*View Projects*, *Contact Me*) and social media profiles.

- **About Me & Education**:
  - Bio highlighting web development focus and problem-solving skills.
  - **Academic Background**:
    - **Bachelor of Computer Applications (BCA)** – *The NorthCap University* (Currently Pursuing).
    - **Class 12th & Class 10th** – *SR Century Public School* (Completed).
  - Key capability highlights (Modern Web Dev, Data & Form Management, Clean Code).

- **Technical Skills**:
  - **Frontend Development**: HTML5, CSS3, JavaScript (ES6+), Responsive Design, Modern CSS & Flexbox/Grid.
  - **Web Apps & Data Handling**: Data Collection Forms, Client-Side Validation, Structured Data Handling, REST API Basics.
  - **Tools & Workflow**: Git, GitHub, VS Code, DevTools, Accessibility.

- **Featured Projects**:
  - **[Student Data Collection Web](https://github.com/Mehak-joon/student-data-collection-web)**:
    - Interactive student registration and academic data platform.
    - Real-time form validation, responsive tables, and structured data flow.
    - Built with HTML5, CSS3, and JavaScript.
  - **Interactive Personal Portfolio**: Responsive portfolio with glassmorphism and theme switching.
  - **Task & Study Planner Web App**: Productivity and study tracker utilizing browser storage.

- **Contact Form with JavaScript Validation**:
  - Real-time input checking on blur and typing.
  - **Email Validation**: Checks for non-empty input and verifies valid email syntax via regular expression before allowing submission.
  - Required validation for Name, Subject, and Message.
  - Inline error notifications and an animated success alert banner on valid submission.
